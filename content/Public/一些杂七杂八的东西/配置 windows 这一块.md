# 美化

主播对美化的需求不是很高，主要看重系统运行的流程程度，所以这里只讲我的简单配置。

- WallPaper：找壁纸。
- 关闭系统动画：这玩意除了提高响应时间基本没用。
- 自动隐藏任务栏：提一嘴，开了动画你就能看到微软屎一般的隐藏动画。
- 桌面基本不放文件，定时清理即可。可以使用软件启动器启动程序。

# 关于编辑器和终端

如果你需要敲代码，不想要一直拖动鼠标或者是什么小众冷门哥的话，你可以选择以下的东西。

首先选择一个趁手的终端模拟器，虽然 windows 自带的终端已经比较好用，还是有几个推荐。

- alacritty：轻量，缺点是没有图片显示协议，没法看图。
- wezterm: 支持键盘选择模式，类似自带终端，有标签页什么的。

终端复用器：

- zellij：用起来比较舒服，支持浮动窗口什么的。
- herdr：agent 特化工作流，实际上似乎没那个必要，windows 上使用体验不是很好。

代码编辑器：

- nvim：原汁原味，就是配置有点麻烦，不过现在可以用 ai 辅助你了。
- vscode：搭配 vim 模式插件还算可以。
- visual studio：也有 vim 插件什么的。

笔记管理：

- obsidian：支持很多插件，主题也很丰富。免费版就够用了，因为直接是 md 文件，笔记可以方便的迁移。并且可以通过 git 进行版本控制和上传 github 进行备份，不想要公开的文件写个 gitignore 就好。
- 思源：朋友说挺好用，但我嫌弃它是自己的格式，还要多导出成 md 的一部。
# 关于键盘

一把能改键位，自带驱动的机械键盘比较重要（我的是前行者 x87），这样你能通过键盘驱动直接修改键位，而不是用 windows 上兼容性普遍狗屎的键位映射工具修改。即使是微软自己写的 powertoys，也总是出现 bug。

你也许需要：

- 给不常用的键映射为组合键。
- 将 win 键映射成别的键。
- 将 capslock 映射为 esc：如果你喜欢 vim 键位，并使用 vim 模式编辑文件。

# 减少鼠标操作

如果你有日益严重的腕管炎，不想被折磨的话，那么我推荐你往下看看。

关于优化鼠标的操作：

- 购买一个人体工学鼠标: 从物理手段上缓解你的手腕。我之前以为这个是一个智商税，但是事实证明并不是，如果你熟悉了这个有些诡异的操作模式的话，那你反而会觉得挺舒服的。
- 购买一个腕托: 如果你使用的是机械键盘的话，键程过高会导致你的手腕不舒服。
- 使用开源软件 alt snap: 优化你的鼠标操作体验。
	- 结合快捷键实现方便的拖拽，比如按在窗口中间就能拖动窗口。
	- 自定义鼠标按键和组合键的功能：比如我设置了 alt+滚轮等变成调整音量。

关于减少鼠标的操作：

- Glazewm：一个平铺式桌面管理器，可以用键盘管理窗口并支持快速切换虚拟桌面，Windows 上别的都不好用，唯独这个还可以。有个搭配的 yasb，隐藏任务栏的情况下显示还可以。不过适应平铺需要一段时间，配置也有点麻烦。自带的窗口划分有点文件，推荐用开源的 GlazeTiler 来解决窗口方向的问题。
- Auto HotKey：一个可以自定义的键盘监听或者别的啥的程序，支持做些特殊操作。比如我将我的左 shift 固定切换为英文，右 shift 固定切换成中文。按下 esc 会同时触发切换为英文和小写状态，避免每次都去看输入法状态。
